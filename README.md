# Mooncake 🌕
中秋祝福语随机显示器 - Mid-Autumn Festival Random Blessing Display

## 功能特点 Features
- 🎯 随机显示20条精美中秋祝福语
- 🔄 页面刷新或点击按钮获取新祝福
- 🎨 优美的渐变背景和月亮主题设计
- 📱 响应式设计，支持手机和电脑访问

## 使用方法 Usage
1. 打开 `index.html` 文件即可使用
2. 每次刷新页面都会显示不同的祝福语
3. 点击"换一句祝福"按钮获取新的祝福语

## 在线预览 Live Demo
直接用浏览器打开 `index.html` 文件，或者：
```bash
# 使用Python启动本地服务器
python3 -m http.server 8080
# 然后在浏览器访问 http://localhost:8080
```

## 祝福语内容 Blessing Contents
包含20条传统中秋祝福语：
- 月圆人圆事事圆，花好灯好好事连，祝你中秋快乐！
- 千里共婵娟，愿你平安喜乐常相伴
- 但愿人长久，千里共此时
- 以及更多温馨祝福...

## 技术实现 Technical Implementation
- 纯HTML + CSS + JavaScript实现
- 无需额外依赖或框架
- 响应式设计，适配各种设备
